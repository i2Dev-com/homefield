# HomeField documentation

Start from the [README](../README.md) for what this is and the quick start.

| Document | Read it when |
|---|---|
| [getting-started.md](getting-started.md) | You are installing for the first time and want the detail behind the README's quick start: the one-liner, `setup`, account types, preflight, tokens, troubleshooting |
| [adopting.md](adopting.md) | You are routing a repository's jobs to the runner: the seven steps, the routing options, `adopt` and the pull request it opens |
| [runbook.md](runbook.md) | You operate a runner: setup, the runner group, switching repositories, failure modes, maintenance, more runners, moving, removal |
| [security.md](security.md) | You want the routing guard's contract and the bypasses found and fixed so far, with the pin each fix makes consumers bump |
| [tap.md](tap.md) | The Homebrew tap: the formula template, the release automation and the `TAP_TOKEN` secret |
| [cli.md](cli.md) | You drive the tool from a script or an agent: every command, option, exit code, environment variable and `--json` shape |

`assets/` holds the banner image and its SVG source; `ideas/` holds notes
